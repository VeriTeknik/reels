# VeriTeknik Reels

Public hosting for the short vertical videos VeriTeknik posts on Instagram, LinkedIn and X.
Files here are referenced by Buffer when it publishes a post, so they must stay at their paths.

- `videos/YYYY/MM/<slug>.mp4`: 1080x1920 H.264 reels.

Every video that shows a "Gerçek çağrı" footnote was rendered from the real output of a VeriTeknik MCP tool call; the footnote names the tool, the server and the time of the call.
